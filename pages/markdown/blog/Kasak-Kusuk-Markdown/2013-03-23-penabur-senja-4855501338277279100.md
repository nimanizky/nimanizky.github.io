# Penabur Senja

Para Penabur Senja  
Mengenalkan Sadisnya Gembira  
Menusuk Kalbu terhitam  
Dan Menyembahnya  
  
Para Penabur Senja  
Menghangatkan Akar ranting  
Mengakhiri masalah genting  
Membakar  
Menghirup Kelamnya  
  
Senja yang kembali datang  
Bersembunyi dibalik tirai biru  
Membentang lika-liku  
Proses kehidupan  
  
Sore yang rimbun  
Mengatur para manusia  
Untuk iba  
dan menangisi kata-kata
