# Pesan

Juwita...  

Kemarin aku nonton grebek juwita

Realita juwita

  

Juwita...

Besok aku mau pergi lho

Yaudah pergi aja

  

Juwita..

Dari kemaren juwita nggak ada

Ya emang nggak ada

  

Juwita

Aku capek Juwita

Tidur yuk Juwita
