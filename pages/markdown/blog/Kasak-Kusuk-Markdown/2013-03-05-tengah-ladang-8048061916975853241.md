# Tengah ladang

Sebenarnya aku tertidur memantau awan  
Tidak untuk menikmati Rokok murah  
Atau sembari minum 2 botol beer  
Atau sambil Bersenang-senang  
  
Bukan  
  
Aku cuma ingin kebaikan dan Perasaanya
