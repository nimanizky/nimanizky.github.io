# Setanganku apa Sekakiku?

<a href="http://4.bp.blogspot.com/-6lkhEqhL_cI/Ui3thRUevsI/AAAAAAAAAZM/TkSUweIzX7c/s1600/000042.JPG" data-imageanchor="1" style="margin-left: 1em; margin-right: 1em;"><img src="http://4.bp.blogspot.com/-6lkhEqhL_cI/Ui3thRUevsI/AAAAAAAAAZM/TkSUweIzX7c/s320/000042.JPG" data-border="0" width="320" height="216" /></a>

  
Ia adalah nona  
Menjalar-jalar dengan hawa napsu  
untuk mencari-cari kepasrahan diri  
  
Ia adalah junta militer  
dan menutup mulutku  
saat aku tak suka menipu  
  
Maha dari segala maha  
Diatas menengadah  
Dibawah berlutut  
  
Diutusnya untuk berbuat dosa!  
Aku hidup dari penyesalan!  
  
Ini kaki ataukah tangan?
