# Jalan penunggu

Para penunggu ini  

kubiarkan berlalu lalang

melewati aku yang hampir mati

  

Sesaat aku duduk termenung

dan bola mataku menunggu sebuah insiden terlewat

Beribu penunggu sudah ku kenal

Beribu sifat sudah terbendung

  

Segera kuberjalan mencari pintu penyelesaian

Menunggu lagi sembari bermain kekesalan

Waktu mulai kusut dan pelan

  

Sudah saatnya bersembunyi dibalik masalah

Masalah teraut dalam wajah para penunggu 

Kalian para penunggu
