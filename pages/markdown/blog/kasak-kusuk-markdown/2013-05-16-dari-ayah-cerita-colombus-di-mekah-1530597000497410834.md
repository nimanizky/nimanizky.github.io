# Dari Ayah: Cerita Colombus di Mekah

Eureka! Eureka!  
  
Tersayat kantong penuh mega-mega  
Yang lambungnya juga penuh dosa  
  
"Ash!Rautmu sendal"  
mengores langkah  
dilumpur  
bekas kencing  
bekas maut  
dengan jejak ban  
pada catatan harian  
  
Eureka! Eureka!  
Ayah telah pulang  
Membawa sekarung uang  
bekas menunggu dibawah jembatan  
Kita merayakan kedatangan  
Dengan whisky,Sampanye  
Yang kita siram  
pada beringin-beringin hujan  
Akarnya menciut,ketetesan  
  
Ada hasil buruan:  
2 beruang, 2 kucing, 2 Anjing  
Tidak ada babi kataku  
Karena Mereka  
Tlah mabok berpesta. Eureka! Eureka!  
  
Colombus! habis lah para ulama  
para pendeta, para manusia, para mamalia  
Dihitungmu aljabar  
Dengan ceramah Akbar!  
  
Phytagoras di Mekah  
menghitung semburat ilahi  
Cahaya pelangi  
Cahaya matahari  
dan Setangkai Api  
  
Itu Ayah mendongeng  
Sambil *Ngebrem* bali  
Sampai Sempoyongan lagi  
  
160513.1044
