# Kau Ini Zina

Beberapa hari yang lalu  
Aku didatangi manusia yang ingin beradu  
Dari mulutnya keluar : Sampah,Lendir,Bau  
Para manusia jijik  
  
Kepadamu para ide datang disore untuk disembah  
Seperti Musa memenggal kepala berhala bedebah  
  
Kepada Pembohong  
Aku memuja-muja disiang bolong  
  
Mereka beribadah  
Beberapa mengalah  
  
Pada Sesaji Manusia  
Untuk membuang Harta
