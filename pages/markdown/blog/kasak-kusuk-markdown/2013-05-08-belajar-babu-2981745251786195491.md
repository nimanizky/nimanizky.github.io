# Belajar Babu

Belajar babu  
Untuk bulan yang menggores kaca depan  
Menyinari aku  
Para majikan  
Dengan Pisau dan Setrika  
  
Ini Wajah-wajah berbedak  
Bekas saksi siksa  
Tidak bisa lepas  
Pada rautnya  
  
Siang  
bulan tidak melayang di atas telaga  
Dimana tempat untuk merana  
Dipersembahkan 2 utas sajen  
Di Mega-mega tersayata luka  
  
Dilayar tanjep kita melihat  
Adegan paralelmu ditayangkan  
Menghadap awan  
Terlihat sebuah tontonan  
Melecehkan harga diri  
Tak dibayar  
Untuk dibabui
