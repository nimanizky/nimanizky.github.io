# Senja Suka Mengamat

Banyak tragedi  

Carut-marut 1 hari ini 

Membuat keterpurukan sendiri

Banyak mayat diseret bawa pulang

Menyayat sekujur tubuh para penderita

  

Sore, menunggu senja

dan diiringi lagu-lagu lama

Memandang sang surya

Pergi untuk mengamatiku sementara

  

Senja bosan

Melihat aku tak punya roh dan bayangan

Senja suka mengamat
